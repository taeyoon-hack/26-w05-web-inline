# 26-w04-web-inline

5주차 실습① — **보안회사 원페이지 웹사이트 (인라인 제작)**

GitHub Copilot **인라인** 기능으로 보안회사 원페이지 웹사이트를 처음부터 끝까지 만들어보는 실습입니다. 섹션 하나씩 HTML을 만들고 바로 CSS로 색을 입히는 과정을 5번 반복하며 완성합니다.

## 시작하기

1. 이 저장소를 **Fork**
2. Fork한 저장소를 로컬에 **Clone**
3. [`guide.md`](./guide.md)를 따라 순서대로 진행

## 만들 결과물

```
nav (앵커링크: Hero / Services / About / Contact)
 └─ hero (회사 슬로건 + 버튼)
 └─ services (서비스 카드 3개, 각 카드에 "자세히 보기" 링크)
 └─ about (회사 소개)
 └─ contact/footer (연락처)
```

파일 구성: `index.html` / `style.css` / `script.js`

## 배포

GitHub Pages로 배포합니다. 자세한 방법은 `guide.md`를 참고하세요.
